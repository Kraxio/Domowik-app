How to back up app data before changing phones

What to save before moving to a new phone and how to transfer local data safely without automatic cloud synchronization.

PLENDEFRESUKCS

Why a backup is necessary

Locally stored data does not automatically appear on a new device. Uninstalling the app, losing the phone or performing a factory reset can remove it. Create the backup before configuring the replacement phone, not after wiping the old one.

What a full backup should contain

A full backup should include all modules, settings and, when supported, photos. CSV or ICS exports are useful for viewing information but may not restore the complete database. Use the format specifically intended for full import when moving devices.

Where to store the file safely

Transfer the file by cable, USB storage, Bluetooth, email or a cloud drive of your choice. If it contains finances, storage locations or document photos, consider password encryption. Keep the password separately, because an encrypted file cannot be recovered without it.

Test before erasing the old phone

Import the backup on the new device and check a selection of records: items, photos, deadlines, accounts and lists. Delete the old copy only after confirming that the data is complete.

How often to back up

For an actively used app, a monthly backup is reasonable, with extra copies before a system update, phone replacement or large import. A backup is useful only when you can locate it and know when it was created.

How Domowik helps

Domowik supports a full JSON backup, exports of selected modules and optional password encryption. Import merges data instead of intentionally replacing the entire database. With no automatic sync, you decide when and where the backup is stored.
